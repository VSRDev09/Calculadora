# Calculadora C# - Windows Forms

## Descrição

Este projeto é uma calculadora básica desenvolvida em C# utilizando a biblioteca Windows Forms. A aplicação permite realizar operações matemáticas simples como adição, subtração, multiplicação e divisão.

## Funcionalidades

* **Operações básicas:** Soma, subtração, multiplicação, divisão, raiz quadrada e potências.
* **Interface intuitiva:** Design simples e fácil de usar.

## Tecnologias Utilizadas

* **C#:** Linguagem de programação principal.
* **Windows Forms:** Framework para criação de interfaces gráficas.
* **Visual Studio:** Ambiente de desenvolvimento integrado.
